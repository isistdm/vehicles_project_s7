# 🚗📊 Proyecto S7 - Análisis Interactivo de Vehículos

Bienvenido a **Proyecto S7**, una aplicación web interactiva desarrollada en **Python** con **Streamlit** y **Plotly Express**.  
Su objetivo es transformar datos de anuncios de venta de vehículos en **gráficos dinámicos y fáciles de interpretar**, permitiendo explorar tendencias y distribuciones de manera visual y atractiva.  

> 💡 Esta aplicación es ideal para quienes desean **analizar datos de forma intuitiva** y aprender cómo integrar herramientas modernas de visualización en proyectos de ciencia de datos.
